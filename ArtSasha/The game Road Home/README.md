# The Game: Road Home 🍎

Невелика аркадна платформна гра про яблуко Джонні, яке вирушає у подорож, щоб знайти дорогу додому.

## Про гру

Джонні має пройти небезпечний світ, подолати перешкоди та дістатися до порталу. На шляху гравця чекають рівні, пастки, історія та трохи пригод у стилі Scratch.

Гра створена як простий і доступний проєкт для коротких ігрових сесій — її можна запускати на комп’ютері або у браузері на телефоні.

## Керування

### Комп’ютер

- `←` `→` — рух персонажа;
- `↑` — стрибок;
- `↓` — рух вниз, якщо це передбачено рівнем.

### Телефон

Гра відкривається у браузері та підтримує повноекранний режим. Для повноцінного touch-керування сенсорні кнопки потрібно додати безпосередньо у Scratch-проєкт.

## Запуск

Відкрийте `index.html` через локальний вебсервер. Для роботи TurboWarp потрібен доступ до `game.php`, який віддає файл Scratch-проєкту `game.sb3`.

Після запуску сторінки натисніть кнопку повноекранного режиму для комфортної гри на телефоні.

## Технології

- Scratch 3.0 / `.sb3`;
- TurboWarp Player;
- HTML5 и CSS3;
- JavaScript;
- PHP для завантаження проєкту;
- адаптивна верстка для комп’ютерів і мобільних пристроїв.

## Структура

```text
index.html   — сторінка гри та адаптивна оболонка
game.sb3     — Scratch-проєкт гри
game.php     — безпечна видача файлу гри для TurboWarp
server.js    — локальний сервер для розробки
```

## Ліцензія

Проєкт створений для навчання, експериментів і розвитку власної гри. Умови використання ресурсів і коду визначаються автором репозиторію.
