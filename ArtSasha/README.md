# Дорога Додому: пригоди Джонні

**Дорога Додому: пригоди Джонні** — це навчально-розважальна 2D-гра, у якій гравець допомагає яблуку Джонні пройти перешкоди та знайти шлях додому.

## Про гру
- Жанр: аркадна платформер-гра
- Платформа: браузер (TurboWarp / Scratch-проєкт)
- Керування: клавіатура
- Мета: дістатися порталу та завершити рівень

## Ідея та місія
Гру створено, щоб через інтерактивний формат привертати увагу до теми відповідального ставлення до природи та довкілля.

Цей проєкт був створений для Всеукраїнської екологічної організації **"Мама-86"**.

## Запуск
1. Відкрийте сторінку гри у браузері.
2. Дочекайтеся завантаження вбудованого плеєра.
3. Керуйте персонажем і проходьте рівень.
